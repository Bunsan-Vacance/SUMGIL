## 사전 고정 판정 기준 대비

- **(a) `full`에서 LightGBM ±2%p → 불충족.** RMSE로 −16.4 / −11.6%p. 다만 MAE는 −4.9 / −4.5%p이고
  등급 일치율은 +0.08%p로 동등하다. 어느 지표로 채택을 판정할지가 145의 첫 결정이다.
- **(b) 절단 증강 GRU가 `no_lag`에서 0%p 이상, `d7_only`에서 양수 → 부분 충족.** RMSE는 여전히 음수지만
  MAE는 `d7_only`에서 양수, 등급은 `no_lag`에서 lookup과 동일. LightGBM 대비 +28.7 / +36.8%p다.
  **"붕괴하지 않는다"는 확인됐고 "lookup을 이긴다"까지는 못 갔다.**
- **(c) 증강이 `full`을 1%p 이상 깎는가 → 승차에서만(−3.4%p), 하차는 오히려 +7.0%p.** 방향이 엇갈려
  시드 1개로는 판정 불가. 145에서 시드 3개 이상 반복이 필요하다.

## 145로 넘기는 것

1. 판정 지표 확정(RMSE/MAE/등급이 서로 다른 답을 준다).
2. **가용성별 예측기 3단 선택** — 이력 완비 → LightGBM, 결손 → GRU, 전무 → lookup. 배치는 이미 이력 일수를
   알고 있다(`meta.history_days_present`).
3. RMSE 격차 원인(z-정규화 + Huber δ=1이 큰 잔차 기울기를 누른다) 1파라미터 실험.
4. 2호선만 `full`에서도 lookup보다 나쁘다(−6.16%) — 원인 확인.
5. 시드 반복(결정성은 확인, 시드 간 분산은 미측정), `--model lstm` 1회 비교.
