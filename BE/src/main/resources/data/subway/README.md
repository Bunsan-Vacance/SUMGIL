| 파일 | 역할 |
| --- | --- |
| `station-aliases.csv` | 원천마다 다른 역명 표기 → 정본 표기. 정본은 서울교통공사 좌표 파일·실시간 API 쪽 ("서울", "총신대입구", "신내", "자양") |

| `korail-line-overrides.csv` | 코레일 구간 파일의 노선 코드는 **물리 선로**(경원선 103 등) 기준이라 서비스 노선과 어긋나는 구간을 (출발역, 도착역) 단위로 바로잡는다. 청량리~회기는 1호선·경의중앙선 둘 다 |
| `station-disambiguation.csv` | 같은 이름의 다른 물리 역을 `(역명, line_id) → station_id` 로 갈라낸다. 현재 데이터 범위(1~8호선 + 코레일 광역)에는 해당 사례가 없어 비어 있다. 신촌(2호선/경의중앙선)처럼 생기면 여기에 적는다 |

## 식별자 규칙

- `station.station_id` = **정규화 역명** (괄호 부기 제거 + 별칭 적용). 물리 역 1행. 노선별 승강장은 `edge_time.route_id` 로 표현한다.
- `line.line_id` = 서울시 실시간 지하철 API 의 `subwayId` (1001~1009, 1063 경의중앙, 1065 공항철도, 1075 수인분당 …). 수집기가 변환 없이 쓰기 위해서다.
- 실시간 API 의 `statnId` 는 `subwayId(4) + 역코드(6, 0 채움)` 이다. 2호선 이상은 좌표 파일의 "고유역번호"와 일치하지만 **1호선은 다르다** (좌표 파일 150~ vs 실시간 API 126~133). 수집기 티켓에서 매핑 표를 만든다.

## 알려진 빈 곳 (채워 넣지 않고 비워 둔 것)

- **9호선**: 좌표만 있고 운행 순서·소요시간 원천이 없어 구간을 만들지 않는다. 신분당선·공항철도·우이신설선·경춘선·신림선도 환승 상대 노선으로만 등장한다.
- **코레일 구간 파일은 100행짜리 부분 데이터**다. 분당선 도곡~개포동, 과천선 대공원~과천, 경원선 덕계~덕정 등이 빠져 있다. 로더의 검증기가 노선별 연결 끊김을 경고로 출력한다. 서울 안 구간 중 데모에 쓰는 선릉~한티~도곡은 들어 있다.
- **코레일 역 좌표**: 위 파일 어디에도 없어 `station.lat/lng` 가 null 이다. 열린데이터광장 역사마스터 API(`subwayStationMaster`, 8088 포트라 실습실 망에서 불가)로 채우는 것이 후속 작업이다.
- **6호선 응암순환**은 실제로 단방향이지만 양방향 엣지로 넣는다. 탐색 결과에 미치는 영향은 6개 역에 한정된다.
- 환승 파일은 1~8호선 환승역만 담는다. 나머지 환승역은 `source=manual` 로 수동 입력할 때까지 비어 있다.
