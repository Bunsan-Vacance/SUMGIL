## 현재 결정

- 화면은 홈 / 검색 / 경로 결과 / 상세 / 길안내 / 도착으로 분리한다.
- 대표 경로 두 개를 먼저 배치하고, 대안 경로는 아래에 계속 노출한다. 별도 펼치기 버튼은 없다.
- 상세·안내 화면의 전체 구간은 항상 펼쳐 표시한다. 시트 스크롤로 확인하며 별도 보기/접기 조작은 없다.
- 정상 작동을 설명하는 상시 문구를 추가하지 않는다. 선택·이동에 필요한 정보와 실제 오류를 표시한다.
- 바텀시트의 클릭·드래그·키보드 조작을 유지한다.
- 전역 상태 라이브러리는 아직 도입하지 않는다. 앱에서 한 번 생성한 기능 훅의 상태를 필요한 화면에 props로 전달한다.
- 실제 카카오 지도와 장소 마커를 사용한다. `VITE_API_BASE_URL` 미설정 환경의 경로 목록·소요시간·혼잡도는 샘플이며, 설정 시 경로 후보와 leg geometry는 백엔드 응답을 사용한다. 계약 합의나 실서버 검증 완료를 뜻하지 않는다.
- 경로 후보의 `congestionPrediction`(퍼센트·서버 등급·데이터 상태·예측 근거)과 `source`는 서버 응답 의미를 보존해 표시한다. 모든 값은 서울 기준 D+0~D+3 예상값이며, 값이 없으면 `예측 정보 없음`을 표시하고 혼잡 사유 설명은 제공하지 않는다. 구간 전환은 선택 `transitionType`을 우선하고 기존 응답도 처리한다.
- 현재 실제 FE 검증은 `http://localhost:5174`에서 수행한다. 기존 `local-stack/FE` 사본은 `http://localhost:5173` 실행용이며 두 환경의 코드를 혼동하지 않는다.
