# 시연 시나리오 — 숨길(S15P21A104)

전제: `https://j15a104.p.ssafy.io` 접속, 모바일 웹 레이아웃.

1. **홈 화면** — 출발지·도착지 입력창이 있는 초기 화면이 뜬다. 최근 검색 기록이 있으면 목록으로 노출된다.
2. **장소 검색** — 출발지 입력창을 눌러 장소명·도로명 주소를 검색한다(카카오 JavaScript SDK 연동). 지도에서 직접 위치를 선택하는 것도 가능하다. 도착지도 같은 방식으로 설정한다. 현재 위치를 출발지로 바로 지정하는 버튼도 있다.
3. **경로 검색 결과(목록)** — 출발·도착이 설정되면 좌표 기반 경로 탐색 API(`POST /api/routes/search/coordinate`)가 호출되어 최대 6개 후보(속도 우선 3 + 혼잡 회피 3)가 목록으로 나온다. 상단의 **"빠른 길" / "덜 붐비는 길"** 탭을 눌러 정렬 기준을 바꿀 수 있다 — "빠른 길"은 소요시간 최단 경로를, "덜 붐비는 길"은 구간 혼잡도가 가장 낮은 경로를 우선 보여준다. 이동수단 필터(지하철·버스·따릉이 조합)로 후보를 좁힐 수 있다.
4. **경로 상세** — 후보 하나를 선택하면 구간(leg)별 상세 화면으로 들어간다. 지하철·버스 구간은 혼잡도 수치에 따라 지도 경로선 색상이 여유/보통/혼잡 단계로 표시되고, 버스 구간은 실시간 도착정보 기반 혼잡 등급이 함께 붙는다. 따릉이 구간이 포함된 경로는 대여소 위치와 인근 재고(대수)가 표시된다.
5. **길안내 시작** — "길찾기 시작"을 누르면 실제 이동 화면으로 전환되어, 다음 구간·환승 정보가 순서대로 안내된다.
6. **(있는 경우) 실시간 재안내** — 이동 중 따릉이 재고가 고갈되는 등 상황이 바뀌면, 재안내 에이전트(TIME)가 대안을 팝업으로 제시한다.
7. **도착 화면** — 목적지 도착을 확인하는 화면으로 마무리된다.
