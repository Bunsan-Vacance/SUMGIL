# 외부 서비스 정보 — 숨길(S15P21A104)

프로젝트에서 사용하는 외부 서비스와 가입·활용에 필요한 정보를 정리한다.

| 서비스 | 용도 | 발급처 | 비고 |
| --- | --- | --- | --- |
| 서울 열린데이터광장 API | 지하철 실시간 도착정보·혼잡도, 따릉이 대여소·재고 | data.seoul.go.kr → 마이페이지 → 인증키 신청 | 일반 인증키 1개로 여러 API 공용, 실시간 지하철 도착은 전용 키 별도 발급 가능 |
| 공공데이터포털(data.go.kr) | 버스 도착정보 조회, 버스 실시간 혼잡도 | data.go.kr 회원가입 → 서비스별 활용신청 승인 후 디코딩 키 발급 | **디코딩(Decoding) 키**를 사용한다(인코딩 키 아님) |
| Kakao Developers | 지도 표시(JS SDK), 도보·자전거 경로 조회(REST API) | developers.kakao.com → 애플리케이션 등록 → 플랫폼(Web) 도메인 등록 | JavaScript 키(FE)와 REST API 키(BE)는 별개 키 |
| GMS(LLM 게이트웨이, OpenAI 호환) | 재안내 에이전트(TIME)의 LLM 호출 | SSAFY 제공 게이트웨이(`gms.ssafy.io`) | 모델 `gpt-5.4-mini` 계열 사용, API 키는 팀 내 별도 채널로 전달 |
| Splunk Enterprise (Free 티어) | (선택) 로그 모니터링·이상탐지 데모 | splunk.com 개인 설치 | 팀 공유 기능 아님 — 개인 로컬 데모 전용, 서비스 동작에는 불필요 |

소셜 로그인·결제 등 사용자 인증이 필요한 외부 서비스는 사용하지 않는다(공개 API 서비스).
